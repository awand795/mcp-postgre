Modul untuk menghubungkan server database eksternal (PostgreSQL, MySQL, MariaDB) ke sistem AI. Setiap koneksi dapat ditambah, diedit, diuji, dan dihapus.

  • 4A. Halaman Daftar & Toolbar Database, semua koneksi database yang terdaftar ditampilkan sebagai kartu (kotak merah).
  • 4B. Wizard Tambah Database (3 Langkah), wizard langkah pertama meminta:
    • nama koneksi/alias — nama tampilan (contoh: "production db")
    • kode — pengenal unik huruf kecil & underscore
    • driver — pilih: postgresql, mysql, atau mariadb
    • centang aktif dan/atau default jika perlu.
  • 4C. Mengelola Koneksi yang Sudah Ada, pada setiap kartu database, klik ikon (kotak merah) untuk membuka modal edit.

Berikut ini adalah tampilan antarmuka menu dari modul 4. DATABASE MANAGEMENT :

Petunjuk Pemakaian :

  • 4A. Halaman Daftar & Toolbar Database

    1. Halaman Daftar Database

    Semua koneksi database yang terdaftar ditampilkan sebagai kartu (kotak merah). Setiap kartu memuat: nama alias, driver (PostgreSQL/MySQL/MariaDB), host:port, status koneksi, dan tombol aksi.

    2. Toolbar: Pencarian, Filter, & View Toggle

    Toolbar (kotak merah) berisi: Kolom Pencarian, Filter Driver, Filter Status, dan Toggle View Grid/List.

    3. Tombol "Test All Connections"

    Klik tombol "Test All" (kotak merah) di pojok kanan atas untuk menguji semua koneksi database sekaligus. Hasilnya ditampilkan dalam health bar: Total, Connected, dan Failed.

    4. Tombol "Tambah Database"

    Klik tombol "+ Tambah Database" (kotak merah) untuk membuka wizard penambahan koneksi baru. Wizard terdiri dari 3 langkah.

  • 4B. Wizard Tambah Database (3 Langkah)

    5. Step 1 — Identitas: Nama, Kode & Driver

    Wizard langkah pertama meminta:
    • Nama Koneksi/Alias — nama tampilan (contoh: "Production DB")
    • Kode — pengenal unik huruf kecil & underscore
    • Driver — pilih: PostgreSQL, MySQL, atau MariaDB
    • Centang Aktif dan/atau Default jika perlu.

    6. Step 2 — Koneksi: Host, Port, Kredensial & Schema

    Isi detail koneksi server:
    • Host — IP atau hostname server database
    • Port — otomatis terisi sesuai driver (5432/3306)
    • Nama Database — nama database asli di server
    • Username & Password — kredensial akses database
    • Schema — klik Load untuk deteksi otomatis

    7. Step 3 — Test Koneksi Sebelum Simpan

    Klik "Test Sekarang" untuk memverifikasi parameter yang diisi. Hasil muncul di bawah tombol: hijau = berhasil, merah = gagal. Setelah berhasil, klik "Simpan Database".

  • 4C. Mengelola Koneksi yang Sudah Ada

    8. Tombol Edit Database

    Pada setiap kartu database, klik ikon (kotak merah) untuk membuka modal Edit. Semua data koneksi yang tersimpan akan terisi otomatis.

    9. Modal Edit Database

    Modal edit menampilkan semua field yang sudah terisi (kotak merah). Ubah field yang perlu diperbarui, lalu klik "Simpan Database".

    10. Badge Status Koneksi

    Di bagian bawah setiap kartu terdapat badge status (kotak merah): Connected, Failed, atau Not Tested.

    11. Copy Host & Nama Database

    Pada detail koneksi di kartu, terdapat tombol copy (kotak merah) di samping Host:Port dan Nama Database. Klik untuk menyalin nilai ke clipboard. Notifikasi toast akan muncul sebagai konfirmasi.

    12. Menghapus Koneksi Database

    Klik ikon (kotak merah) pada kartu database yang ingin dihapus. Dialog konfirmasi SweetAlert akan muncul. ⚠ Database bertanda Default tidak dapat dihapus.
