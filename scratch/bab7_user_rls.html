Berikut ini adalah tampilan antarmuka menu dari modul 7. USER MANAGEMENT :

Petunjuk Pemakaian :

  • 7A. Tampilan Tabel User & Aksi Header

    1. Halaman Daftar User (Tabel)

    Semua pengguna ditampilkan dalam tabel (kotak merah) dengan kolom: Nama, Email, Role, Hak Akses, AI Models, API Keys, Cakupan, Dibuat, dan Aksi.

    2. Header Aksi: Template, Import, Export & Tambah User

    Di pojok kanan atas terdapat 4 tombol (kotak merah):
    • Template — unduh file CSV contoh
    • Import — impor user massal dari CSV
    • Export — ekspor semua data user
    • Tambah User — tambah akun manual

    3. Filter & Pencarian User

    Di bawah header terdapat form filter (kotak merah): Kolom Cari (nama atau email) dan Dropdown Filter Role. Klik "Filter" untuk menerapkan atau "Reset" untuk membersihkan.

  • 7B. Menambah & Mengedit User

    4. Tombol "Tambah User"

    Klik tombol "+ Tambah User" biru (kotak merah) di header untuk membuka form tambah akun baru.

    5. Modal Form Tambah User

    Form tambah user (kotak merah) berisi: Nama Lengkap, Email (wajib unik), Password (min. 8 karakter), Konfirmasi Password, Role, dan opsi Is Admin / Is Super Admin.

    6. Field Nama & Email (Wajib Diisi)

    Field Nama Lengkap dan Email (kotak merah) adalah field wajib. Email harus berformat valid dan belum terdaftar di sistem.

    7. Dropdown Pilih Role

    Dropdown Role (kotak merah) menampilkan semua role dari modul Role Management. Pilih role yang sesuai. User tanpa role tidak bisa menggunakan chatbot dengan data spesifik.

    8. Tombol Edit User & Modal Edit

    Pada baris user, klik tombol Edit (kotak merah) untuk membuka modal edit. Semua data user terisi otomatis. Kolom password kosong — isi hanya jika ingin mengganti password.

    9. Modal Edit User — Data Terisi Otomatis

    Modal edit (kotak merah) identik dengan modal tambah, namun semua field sudah terisi. Ubah field yang perlu diperbarui, lalu klik "Simpan".

  • 7C. Import & Export Data User

    10. Unduh Template CSV

    Klik tombol "Template" (kotak merah) untuk mengunduh file CSV contoh dengan header: name, email, password, role, is_admin. Gunakan file ini sebagai dasar sebelum impor massal.

    11. Import User dari File Excel/CSV

    Klik tombol "Import" (kotak merah) untuk membuka modal impor. Unggah file Excel/CSV sesuai template. Sistem memvalidasi setiap baris dan membuat akun secara massal. Error per baris akan dilaporkan.

    12. Export Data User

    Klik tombol "Export" (kotak merah) untuk mengunduh seluruh data user. Data yang diekspor mencakup semua informasi user kecuali password.

  • 7D. Konfigurasi AI per User (Delegasi)

    13. Tombol AI Config (per User)

    Pada kolom Aksi setiap baris user, klik tombol biru berbentuk robot/chip (kotak merah). Fitur ini memungkinkan Admin mendelegasikan model dan API key tertentu khusus untuk satu user.

    14. Modal Konfigurasi AI per User

    Modal AI Config menampilkan daftar semua model dan API key yang tersedia. Centang model dan key yang ingin didelegasikan untuk user ini sehingga penggunaan AI dapat dikontrol per individu.

  • 7E. Row Level Security (RLS) — Filter Data Baris
    Referensi Cepat: Operator Kondisi Filter
    Operator Arti Contoh
    =Sama persiskode_cabang = 1271
    !=Tidak samastatus != inactive
    >Lebih besartotal > 1000
    <Lebih kecilumur < 30
    LIKEMengandung teksnama LIKE Beras
    INDalam daftarkota IN Jakarta,Bandung

    15. Apa itu Row Level Security?

    Row Level Security (RLS) adalah fitur pembatasan data di level baris. Dengan RLS, Admin dapat membatasi baris data yang bisa dianalisis AI untuk user tertentu.

    Contoh kasus:
    • User Cabang Jakarta → hanya bisa melihat data di mana kode_cabang = 'JKT'
    • User Salesman A → hanya bisa melihat data di mana id_salesman = 12
    • User Divisi Finance → hanya bisa melihat data di mana divisi = 'finance'

    Tanpa RLS, user dapat melihat seluruh isi tabel yang diizinkan rolenya.

    16. Tombol RLS — Buka Modal Filter Data

    Pada kolom Aksi setiap baris user, klik tombol hijau (kotak merah). Jika user sudah memiliki filter aktif, badge angka kecil berwarna akan muncul di atas tombol menunjukkan jumlah filter yang terpasang.

    17. Modal RLS — Daftar Tabel Terdeteksi

    Modal Pembatasan Data (Row-Level Security) terbuka menampilkan daftar tabel yang terdeteksi di panel kiri (kotak merah). Setiap tabel yang sudah memiliki filter menampilkan badge N filter.

    Di pojok kanan atas terdapat tombol "Salin" untuk menyalin konfigurasi RLS dari user lain.

    18. Pilih Tabel & Tambah Kondisi Filter

    Klik nama tabel di panel kiri untuk membuka area pengaturan kondisi di panel kanan. Panel kanan menampilkan:
    • Nama tabel yang dipilih
    • Daftar aturan filter yang sudah ada
    • Tombol "+ Tambah Kondisi" (kotak merah) untuk menambah rule baru

    Setiap aturan filter terdiri dari 3 bagian:
    1. Kolom — pilih kolom dari dropdown (beserta tipe data)
    2. Operator — pilih dari: = sama dengan, != tidak sama, > lebih besar, < lebih kecil, LIKE mengandung teks, IN dalam daftar
    3. Nilai — ketik nilai yang menjadi batasan (contoh: 1271, Jakarta)

    19. Preview Data & Simpan Perubahan

    Sebelum menyimpan, klik tombol "Preview Data (5 Baris)" (kotak merah) untuk melihat contoh 5 baris data yang akan tampil sesuai kondisi filter yang diset. Ini memastikan filter sudah benar sebelum diterapkan ke user.

    Setelah yakin, klik "Simpan Perubahan" biru di bawah modal. Klik "Batal" untuk menutup tanpa menyimpan.

    Tips penting:
    • Kosongkan semua kondisi untuk mengizinkan user melihat seluruh data tabel tersebut
    • Satu tabel bisa memiliki lebih dari satu kondisi (AND logic)
    • Kondisi berlaku untuk semua pertanyaan AI yang melibatkan tabel tersebut

  • 7F. Menghapus User

    20. Tombol Hapus User

    Klik tombol merah (kotak merah) di kolom Aksi pada baris user yang ingin dihapus. Dialog konfirmasi SweetAlert akan muncul.

    21. Konfirmasi Hapus User

    Dialog SweetAlert (kotak merah) menampilkan nama user yang akan dihapus. Klik "Ya, Hapus" untuk menghapus akun secara permanen beserta seluruh data terkait (konfigurasi AI, filter RLS, riwayat chat). Tindakan ini tidak dapat dibatalkan.
