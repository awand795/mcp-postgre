Operator Fungsi Contoh

69

Apa itu Row Level Security?

Row Level Security (RLS) adalah fitur pembatasan data di level baris. Dengan RLS, Admin dapat membatasi baris data yang bisa dianalisis AI untuk user tertentu.

Contoh kasus:
• User Cabang Jakarta → hanya bisa melihat data di mana kode_cabang = 'JKT'
• User Salesman A → hanya bisa melihat data di mana id_salesman = 12
• User Divisi Finance → hanya bisa melihat data di mana divisi = 'finance'

Tanpa RLS, user dapat melihat seluruh isi tabel yang diizinkan rolenya.
KONSEP ROW LEVEL SECURITY

72

Pilih Tabel & Tambah Kondisi Filter

Klik nama tabel di panel kiri untuk membuka area pengaturan kondisi di panel kanan. Panel kanan menampilkan:
• Nama tabel yang dipilih
• Daftar aturan filter yang sudah ada
• Tombol "+ Tambah Kondisi" (kotak merah) untuk menambah rule baru

Setiap aturan filter terdiri dari 3 bagian:
1. Kolom — pilih kolom dari dropdown (beserta tipe data)
2. Operator — pilih dari: = sama dengan, != tidak sama, > lebih besar, < lebih kecil, LIKE mengandung teks, IN dalam daftar
3. Nilai — ketik nilai yang menjadi batasan (contoh: 1271, Jakarta)
TAMBAH KONDISI FILTER
LIHAT KOTAK MERAH
73

Preview Data & Simpan Perubahan

Sebelum menyimpan, klik tombol "Preview Data (5 Baris)" (kotak merah) untuk melihat contoh 5 baris data yang akan tampil sesuai kondisi filter yang diset. Ini memastikan filter sudah benar sebelum diterapkan ke user.

Setelah yakin, klik "Simpan Perubahan" biru di bawah modal. Klik "Batal" untuk menutup tanpa menyimpan.

Tips penting:
• Kosongkan semua kondisi untuk mengizinkan user melihat seluruh data tabel tersebut
• Satu tabel bisa memiliki lebih dari satu kondisi (AND logic)
• Kondisi berlaku untuk semua pertanyaan AI yang melibatkan tabel tersebut
