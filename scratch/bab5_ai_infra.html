Pusat kendali seluruh infrastruktur AI: mendaftarkan provider (OpenAI, Gemini, dll), mengelola API Key & Model, serta memantau kesehatan key via Health Check.

  • 5A. Halaman AI Management & Statistik, bagian atas menampilkan 4 kartu statistik ai (kotak merah): total provider, api keys aktif, total model, dan provider aktif.
  • 5B. Mengelola Provider AI, klik tombol "+ tambah provider" (kotak merah) di header untuk mendaftarkan penyedia ai baru.
  • 5C. Mengelola API Keys, klik tab "keys" (kotak merah) pada kartu provider untuk melihat semua api key yang terdaftar.
  • 5D. Mengelola Model AI, klik tab "models" (kotak merah) untuk melihat daftar model ai yang didukung provider ini.
  • 5E. Health Check — Uji Validitas API Key, klik tombol "health check" (kotak merah) pada baris api key.

Berikut ini adalah tampilan antarmuka menu dari modul 5. AI INFRASTRUCTURE :

Petunjuk Pemakaian :

  • 5A. Halaman AI Management & Statistik

    1. Halaman AI Management — Statistik Utama

    Bagian atas menampilkan 4 kartu statistik AI (kotak merah): Total Provider, API Keys Aktif, Total Model, dan Provider Aktif. Di bawahnya terdapat grid kartu provider.

    2. Grid Kartu Provider AI

    Setiap provider AI ditampilkan sebagai kartu terpisah (kotak merah). Kartu menampilkan: logo provider, jumlah key aktif, jumlah model, toggle aktif/nonaktif, dan tab Keys/Models.

  • 5B. Mengelola Provider AI

    3. Tombol Tambah Provider Baru

    Klik tombol "+ Tambah Provider" (kotak merah) di header untuk mendaftarkan penyedia AI baru.

    4. Modal Form Tambah Provider

    Form (kotak merah) meminta: Nama Provider, Kode Unik (huruf kecil, misal "openai"), Base URL API, dan Status Aktif. Klik "Simpan" setelah semua terisi.

    5. Toggle Aktif/Nonaktif Provider

    Pada kartu provider, terdapat toggle switch (kotak merah). Klik untuk mengaktifkan atau menonaktifkan provider. Provider nonaktif tidak digunakan chatbot meskipun punya key yang valid.

    6. Menghapus Provider

    Klik tombol Hapus (kotak merah). Dialog konfirmasi akan muncul. Menghapus provider juga menghapus semua API Key dan Model di bawahnya — tidak dapat dibatalkan.

  • 5C. Mengelola API Keys

    7. Tab "Keys" pada Kartu Provider

    Klik tab "Keys" (kotak merah) pada kartu provider untuk melihat semua API Key yang terdaftar.

    8. Tombol Tambah API Key

    Klik tombol "+ Tambah Key" (kotak merah) di dalam tab Keys untuk mendaftarkan token API baru.

    9. Modal Form Tambah API Key

    Form tambah key (kotak merah) meminta: Nama Key (label deskriptif), Nilai API Key (token rahasia dari provider — disamarkan), Batas Token/Bulan (opsional), dan Status Aktif.

    10. Tombol Edit API Key

    Klik ikon Edit (kotak merah) di samping nama key untuk memperbarui label, batas token, atau status aktif. Nilai key asli tidak ditampilkan ulang demi keamanan.

    11. Tombol Reset Limit Token

    Jika key mencapai batas token bulanan, klik "Reset Limit" (kotak merah) untuk mereset counter penggunaan ke nol.

  • 5D. Mengelola Model AI

    12. Tab "Models" pada Kartu Provider

    Klik tab "Models" (kotak merah) untuk melihat daftar model AI yang didukung provider ini.

    13. Tombol Tambah Model AI

    Klik tombol "+ Tambah Model" (kotak merah) untuk mendaftarkan model baru.

    14. Modal Form Tambah Model AI

    Form model (kotak merah) meminta: Model ID (identifier teknis dari provider — contoh: gpt-4o-mini, gemini-1.5-flash), Nama Tampilan, Tipe Model, Max Token, dan Status Aktif.

  • 5E. Health Check — Uji Validitas API Key

    15. Tombol Health Check

    Klik tombol "Health Check" (kotak merah) pada baris API Key. Tombol ini memanggil API provider secara langsung untuk memverifikasi key masih valid dan tidak melampaui rate-limit.

    16. Hasil Health Check

    Modal Health Check (kotak merah) menampilkan hasil pengujian: status key (Valid/Invalid/Rate Limited/Expired), waktu respons, pesan error jika ada, dan rekomendasi tindakan.
